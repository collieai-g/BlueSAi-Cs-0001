# 可靠交接流程

第一個開發里程碑在既有客服 Engine 加入持久回覆期限、獨立監察與本地交接工作。介面仍使用原有客服卡片；整體開發次序見 [開發計劃](DEVELOPMENT_PLAN.md)。

## 回覆期限

AI 處理中的對話收到新問題時，在保存收件的同一交易建立 `response_windows` 記錄。`opened_at` 是本機接收並準備持久保存的時間，`deadline_at` 預設為其後 30 秒，`first_message_id` 指向該輪最早的問題。供應商訊息時間仍保留原有用途，不拿它延長本機期限。

同一輪連續來訊保留最早期限；重複 webhook 不新增訊息或期限。草稿、批准或進入待發送佇列都不算已提交回覆。生成前後、批准及發送提交前均檢查期限，以 `now >= deadline_at` 判斷到期。

Engine 啟動後每 250ms 使用獨立監察檢查期限，不等待模型或供應商網絡回應。到期在同一 SQLite 交易中轉為 `waiting`、提升對話版本、取消未提交草稿／發送、結束該輪工作，並建立一項本地交接工作。長時間停機或事件迴圈阻塞不能保證準時；恢復時補處理，發送前的同步期限檢查繼續生效。

## 期限狀態

| 狀態 | 意義 |
| --- | --- |
| pending | 等待合適回覆提交；草稿或排隊仍屬此狀態。 |
| submitted | 已跨過模擬／供應商提交邊界；不代表供應商接受或訊息送達。 |
| waiting_customer | 已提交必要追問，等待客戶補充；新來訊可開始新的期限。 |
| handed_off | 超時、模型要求人工或生成故障，已轉為等待人工。 |
| cancelled | 人工接管、明確交回或其他控制權變更結束此輪。 |

一個對話同時最多一個 pending 期限。人工接管後不再自動回覆；明確交回 AI 不會重放舊問題，新來訊才開始新一輪。對話版本與設定 revision 繼續攔截過期答案，遲到的成功或失敗結果均不能推翻新的人工控制或問題狀態。

## 人工工作與在途訊息

`handoff_tasks` 每個期限最多一項，記錄個案、期限 ID、原因、建立時間及 pending 狀態。這是**本地已保存的交接工作**，目前沒有私人 WhatsApp 傳送器，不能解讀為已發出或送達通知。既有工作頁可依對話 waiting 狀態讓操作員接手。

模型生成與待發送處理使用各自的單一執行保護。即使舊模型尚未回應，操作員接手後的人工回覆仍可由發送路線繼續處理，不必等舊答案完成。

供應商呼叫前，同步保存 sending 及該輪 submitted 狀態。已提交的訊息保留在途證據；其後接管不承諾撤回。供應商回應不明仍標為 uncertain，重啟亦不盲目重發。這個提交邊界不提供外部恰好送達一次的保證。

## 資料升級與恢復

`schema_migrations` 的第一版遷移新增 `response_windows`、`handoff_tasks` 及相關索引；交易失敗回滾，遇到較新版本資料庫則拒絕啟動。商戶設定、知識批准／有效期、對話、訊息及原有 jobs 不重建。刪除對話時，對應期限與交接工作依外鍵一併清除。

舊對話不倒填期限；升級後的新來訊才開始計時。重啟時保留已保存的原期限，先恢復工作狀態，再立即把已到期的 pending 期限轉人工。重複啟動及監察不重複建立交接工作。

正式資料目錄仍為原有 `.blueprint-service`，3101 配置工作台使用獨立 `.bluesai-local-workbench`。實際升級前正常停止程序並備份整個資料目錄；不要把不同程序指向同一個 SQLite。本次驗收使用暫存或記憶體資料庫，未升級正在運行的使用者資料。

## 驗收方式與範圍

執行 `npm test` 及 `npm run check`。新增的 `test/handoff.test.js` 使用可控制時鐘、延後完成的模型／供應商及舊版資料庫樣本，驗證：

- 30 秒邊界、模型等待期間獨立交接，以及遲到答案攔截。
- 連續來訊與重複事件不延後期限，草稿及排隊不能越過期限發送。
- 過期期限跨重啟恢復、舊資料原文／批准狀態保留及遷移重跑安全。
- 人工接管／交回、新來訊、人工回覆保存及在途結果不明不重發。

2026-10-24 本機驗證：全套 49 項測試通過，其中新增交接測試 19 項；`npm run check` 及文件相對連結檢查通過。人工回覆在舊模型尚未完成時可繼續處理；舊模型遲到失敗和較早的在途回覆完成，均不會破壞新一輪期限。此次只修改後台、測試與文件，未更改卡片介面。

未包括 DOT 訂閱、服務身份、藍圖同步、私人通知傳送、個案轉發指令、完整送達事件或生產 SLA；這些按開發計劃分階段實作及驗收。
