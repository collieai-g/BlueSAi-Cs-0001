# 客服卡片的真實接駁流程

版本：0.4.0-preview.1。入口：AI → Agent 工作台 → 客服卡片 → 管理 → 渠道狀態與接駁。

管理先顯示實際渠道狀態；已連接的帳戶不必重新走完整教學。只有缺項時才前往對應下一步，例如手機待掃碼、收件設定待核對或回覆範圍未開放。下列完整流程供初次設定或需要重新接駁時使用。

本次 WhatsApp 驗收以真實手機收發為準。教學閱讀、離線規則、模擬 provider 及網頁聊天的結果各自標示，不當作 WhatsApp 完成證據。

## 接駁 WhatsApp

1. **準備真實接駁服務。** 安裝人員先啟動指定的 Evolution instance 或本機連結裝置服務，設定私人憑證與固定 callback。未運行時卡片說明缺少服務，不能取得真正 QR。需要協助時可先請目前 AI 整理安裝步驟草稿；這個按鍵本身不會安裝服務或開通帳戶。
2. **本人連結手機。** 按「取得二維碼」。在已登入 WhatsApp 的手機打開「已連結裝置 → 連結裝置」，完成手機要求的身份確認，再掃描電腦上的 QR。iPhone 從設定或個人頭像進入，Android 從三點選單進入。QR 過期就重新取得；卡片只顯示真實服務回傳的 QR。完成後按「檢查連線」。
3. **核對接收範圍及入口。** 選定本人指定的測試號碼，核對 test allowlist 及 webhook。手機 open 只表示裝置已連結，不保證來訊已進入客服；callback 的網址、驗證及可達性須另外檢查。空 allowlist 的本機測試橋接只允許連結裝置，不轉送或發送其他客戶訊息。
4. **真實試收、試覆。** 用指定的另一個測試 WhatsApp 號碼傳送清楚標示的測試訊息。在卡片「收件匣」核對同一筆來訊，人工核對草稿或接手回覆；依用戶授權開啟測試發送後，在收件手機確認實際收到。provider accepted 不當成 delivered；結果不明先在手機核對，不盲目重發。

首次測試可以只用人工或已確認 FAQ，不需要模型金鑰。要評估 AI 後備，可選本機原生 Codex CLI 或自己的模型 API；只填真實已確認商戶資料、批准有效知識，再另外選擇後備與發送政策。

手機操作參考 [WhatsApp 官方連結裝置說明](https://faq.whatsapp.com/1317564962315842/)；第三方連結裝置服務的實作與限制見 [WHATSAPP_RUNTIME.md](WHATSAPP_RUNTIME.md)，官方手機說明不代表為第三方服務背書。

## 只有自己的 WhatsApp 也可先測回覆

1. 先核對 WhatsApp open 及自身新文字確實出現在「連線測試」。
2. 在管理另開「本人對話回覆測試」，閱讀並同意只測目前帳戶；要試 FAQ，再開啟其獨立自動 FAQ 選項，並確認全域知識庫優先及已確認答案自動回覆已獲批准。
3. 核對知識庫有唯一、已批准且有效的 Hello 完整問題；從手機再傳一則新 Hello。舊訊息不重跑，卡片與手機各自核對真正結果。
4. 在該測試對話用專用人工回覆欄核對並提交。它會暫停該對話的自動 FAQ；要再試自動，明確交回後再傳新 Hello。結果不明先核對手機，不重按發送。

預設只讀、停止條件及驗收界線見 [SELF_REPLY_TEST.md](SELF_REPLY_TEST.md)。這不需要模型，不開放外部顧客發送；斷線、重啟、換帳戶或撤銷後須重新確認。

## 接駁原生 Codex 後備

1. 確認這是本人可管理的可信本機，Codex CLI 已由本人登入 ChatGPT，客服核心與渠道程序正在運行。不要把登入檔貼入卡片、聊天或 Git；只有安裝人員可以設定可信執行檔位置。
2. 在管理選擇原生 Codex 並明確同意。後台核對 CLI 版本、登入及一次真正合成推理，會使用帳戶額度；全部成功才切換 adapter。它沒有喚醒或控制目前左側聊天。
3. 保持 AI 自動發送關閉，啟用 FAQ 優先及 `aiFallback` 後，先用另一個已授權帳戶測試一個未完全命中 FAQ、但已批准知識足以回答的問題；核對草稿及實際引用。無依據、退款或衝突應轉人工，澄清先存草稿。
4. 真正需要自動發送時，再明確開啟 `automaticAi` 及當前渠道範圍；到收件手機核對同一筆結果。原生生成最多 25 秒，失敗或逾時轉人工；關閉 fallback 可恢復 FAQ-only／人工。CLI 合成測試不能代替真實渠道驗收。

FAQ 自動答案、AI 後備與 AI 自動發送是不同開關。自傳收件預設只讀；明確開啟獨立「本人對話回覆測試」後，可對新的自身文字測已批准 FAQ 自動回覆及專用人工回覆，仍不建立 CLI、API 或 DOT 工作。詳細配置、原生限制及將來雲端選擇見 [INSTALL.md](INSTALL.md#原生-codex-與選用-api)。

## 不成功時怎樣處理

| 畫面／現象 | 下一步 |
| --- | --- |
| 未準備服務、沒有 QR | 先啟動接駁服務並核對私人設定；保留未連接狀態 |
| QR 過期或手機仍 connecting | 重新取得 QR，由本人再次連結，再檢查狀態 |
| 手機已連結，卡片沒有來訊 | 核對測試號碼 allowlist、收件網址及 webhook 驗證；用同一指定號碼重做一次收件測試 |
| 已收到來訊，但沒有對外回覆 | 檢查發送開關、人工狀態、必要商戶設定、來源有效性及窗口；人工接手後仍可核對回覆 |
| 只見 accepted 或 uncertain | 到收件手機及供應商核對；未有送達證據不宣稱已收到，不自動重發 |
| 宿主只顯示卡片，操作無法保存 | 宿主仍缺 renderer／受限 API；先補該能力，不覆蓋工作室其他頁面 |

## 網頁渠道及離線示範

「接駁網頁」是可選的另一條客人渠道。開啟後可取得 `/chat` 網址，僅提供受限會話，不公開管理員工具；localhost 只限同機。其收件成功不代表 WhatsApp 手機收件。

離線規則只示範已確認文字的固定分類問答，不能當作完整 AI 效果。`/diagnostics/console` 是獨立診斷工具，不是客服 Agent 的正式介面。

閱讀完「完成教學」不會改變手機連線、測試號碼、發送開關或驗收狀態。原生 Codex／DOT 交接仍由本人確認；安裝指引任務只保存草稿，不自行部署私人工作室。
