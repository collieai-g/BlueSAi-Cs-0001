# 由按鍵開始接駁客服

版本：0.3.0-preview.1。入口：客服卡片 → 配置客服 → 接駁。

## 接駁 WhatsApp

1. 按「接駁 WhatsApp」。第一步說明手機及接駁服務的準備。需要安裝協助時，按「請 AI 準備 WhatsApp 安裝指引」，核對任務，再交給目前 Codex／DOT 整理步驟草稿；這個按鍵不會自行購買服務或部署主機。
2. 按「下一步」，再按「取得二維碼」。在手機開啟 WhatsApp；iPhone 使用設定或個人頭像，Android 使用右上角三點選單。進入「已連結裝置 → 連結裝置」，完成手機身份確認，掃描電腦上的二維碼。回到工作台按「檢查連線」。沒有二維碼時仍能閱讀完整教學；服務只會顯示供應商真正回傳的二維碼。
3. 下一步按「設定並核對收件網址」。這只在真正客服執行器顯示；安裝人員先準備服務及私人設定。按鍵向供應商登記 webhook，再讀回比對網址、驗證及事件；讀回成功仍要實際來訊測試。
4. 用另一個測試號碼傳訊，打開「客戶對話」核對。確認草稿或人工接手後回覆，在測試手機看有沒有收到。發送開關關閉時只驗收來訊及草稿；開啟發送由安裝人員按用戶選擇另行設定。

「上一步」「返回接駁選項」保留已輸入的表單。最後的「完成教學」只結束閱讀，不會改變渠道連線或發送設定。連線、收件、渠道接受、送達及已讀各按實際結果顯示。

手機選單步驟依 [WhatsApp 官方連結裝置說明](https://faq.whatsapp.com/1317564962315842/) 核對。此版本實作 Evolution 的連結裝置路線；官方手機說明不代表 WhatsApp 為第三方接駁服務背書。供應商技術設定見 [WHATSAPP_RUNTIME.md](WHATSAPP_RUNTIME.md)。

## 接駁網頁

1. 按「接駁網頁」。服務未準備好時可請目前 AI 整理安裝步驟草稿；沿用現有資源，新增費用先由用戶決定。
2. 服務開啟後顯示真正的 `/chat` 聊天網址，可複製或開啟測試。未開啟不製造可用網址；localhost 清楚標示只限同一部電腦。
3. 把公開 HTTPS 聊天網址加入原有網頁的「聯絡客服」按鈕。頁面提供簡單連結碼，不要求把管理員登入交給客人。
4. 在客人聊天頁發問，到工作台核對同一筆來訊，批准或人工回覆，再回客人頁查看結果。未批准草稿不會向客人顯示。客人瀏覽器呈現並回覆確認後才標為已送達。

## 三個不同入口

| 入口 | 用途 |
| --- | --- |
| 3100 `/workbench.html` | 真正客服服務的設定、訓練及接駁教學 |
| 3100 `/console` | 同一服務的客戶對話、人工接手及批准發送 |
| 3101 隔離預覽 | 自己的本機資料及教學，沒有對客收發 worker |

導覽不會發送其他對話訊息；呼叫 Codex／DOT 仍由本人在目前客戶端確認。安裝任務保存的是指引草稿，實際部署按另外明確的用戶指示執行。
